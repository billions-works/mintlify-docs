The official plugin adds Billions as a WooCommerce payment gateway. It is
standalone and does not require Composer, Guzzle, or the Billions PHP SDK.

## Compatibility

- PHP 8.1 or newer
- WordPress 6.7 or newer
- WooCommerce 10.5 or newer
- Classic Checkout
- Cart and Checkout Blocks
- High-Performance Order Storage (HPOS)

## Install the plugin

<Steps>
  <Step title="Download the plugin">
    Download the [repository source ZIP](https://github.com/billions-works/billions-payments-for-woocommerce/archive/refs/heads/main.zip).
    This is the current source archive, not a versioned release asset. Check
    the plugin version and contents before installing it on a production site.
  </Step>
  <Step title="Upload it to WordPress">
    In WordPress, open **Plugins → Add New Plugin → Upload Plugin**, choose the
    ZIP file, and install it.
  </Step>
  <Step title="Activate the plugin">
    Activate **Billions Payments for WooCommerce**.
  </Step>
  <Step title="Configure the gateway">
    Open **WooCommerce → Settings → Payments**, select Billions, and configure
    the settings described below.
  </Step>
</Steps>

## Gateway settings

| Setting | Purpose |
| --- | --- |
| Enable/Disable | Makes the Billions gateway available at checkout when the other required settings are valid. |
| Title | Payment method name shown to customers. |
| Description | Customer-facing checkout description. |
| Billions API key | Production API key, stored as a password field. |
| Invoice currency | Must match the WooCommerce order currency. |
| Debug logging | Logs API request paths and errors in WooCommerce; it does not log the API key or full callback body. |

<Warning>
  This plugin has **no sandbox mode or API-host setting**. Its API client is
  fixed to `https://api.billions.works`. A staging WordPress site using this
  plugin still calls production. Do not enter a sandbox key expecting a test
  payment; use the [custom API sandbox flow](/integration/sandbox-testing) for
  integration tests instead.
</Warning>

## Payment behavior

The plugin:

1. Creates a Billions invoice for the WooCommerce order.
2. Stores the invoice ID using WooCommerce order APIs.
3. Redirects the customer to the hosted payment page.
4. Receives the Billions callback.
5. Retrieves the invoice from the authenticated API.
6. Updates the order using only the API response.

Invoice creation uses both an idempotency key and `order_no` derived from the
site and order IDs, making retries safe.

## Currency behavior

The store currency must match the configured Billions invoice currency. USD and
EUR orders are supported directly: the invoice uses the store currency and the
customer chooses an available cryptocurrency on the hosted payment page.

A supported cryptocurrency can also be used as the WooCommerce base currency
when it has been registered with WooCommerce.

## Current limitations

- Refunds are not supported.
- Subscriptions and recurring payments are not supported.
- Saved payment methods are not supported.

## Troubleshooting

- If the gateway is absent at checkout, confirm that it is enabled, has an
  API key, and its invoice currency matches the order currency.
- If invoice creation fails, check the WooCommerce logs when debug logging is
  enabled and confirm that the server can reach `api.billions.works` over HTTPS.
- If an order remains on hold after payment, check that the WooCommerce
  callback URL is public and the plugin can retrieve the invoice from the
  authenticated API. A customer's return from checkout does not mark it paid.

<Warning>
  Back up the site and test plugin updates in a staging environment before
  deploying them to a production store.
</Warning>
