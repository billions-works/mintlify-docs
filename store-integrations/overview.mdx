Platform integrations package invoice creation, customer redirection, and
payment verification for a store or billing system.

WooCommerce and WHMCS modules currently connect to production only; they do
not have a sandbox API-host setting. BILLmanager is different: its API origin
can be set to the [sandbox host](/store-integrations/billmanager#configure-the-payment-method)
with sandbox credentials. For a custom integration, see
[sandbox testing](/integration/sandbox-testing).

Existing payment modules may also be connected through the
[Unified Merchant API](/integration/unified-merchant-api). This is a
separate integration path from the official Billions modules.
